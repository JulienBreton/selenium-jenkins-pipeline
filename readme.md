# Pipeline Jenkins – projet d'apprentissage

## Mettre en place un pipeline Jenkins ✅

Un pipeline Jenkins permet d'enchaîner automatiquement les actions d'un build.
Exemple : récupération d'une branche Git, réinitialisation des bases de données, indexation des données, vérification que la plateforme de test est prête, exécution des tests Selenium, contrôle de l'intégrité des données, vérification des métriques (performances, nombre de requêtes…), génération d'un rapport de tests.

## Utiliser un agent Jenkins permanent ✅

Un agent Jenkins permanent permet d'exécuter des actions sur le serveur (exemple : récupération d'une branche Git).
On peut ainsi automatiser la préparation de la plateforme de test.

## Configurer un JDK dans les Tools de Jenkins ✅

La configuration d'un JDK dans Jenkins permet d'exécuter les tests Selenium (Java) sur un serveur qui ne dispose pas de la version souhaitée du JDK.

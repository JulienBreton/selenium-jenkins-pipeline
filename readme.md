Objectifs du repo :

Un pipeline Jenkins permet de mettre en place une chaine d'actions pour un build.
Exemple : installation d'une branche Git, réinitialisation des bases de données, indexation des données, vérification que la plateforme de test est prête, exécution des tests Selenium, contrôle de l'intégrité des données, vérification des métriques (performances, nombre de requêtes...).

* apprendre à mettre en place un pipeline Jenkins ✅️
* apprendre à utiliser un agent Jenkins permanent ✅️
* configurer un JDK dans les Tools de Jenkins ✅️
